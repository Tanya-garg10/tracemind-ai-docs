## [Unreleased]

### Added
- **Incident Replay** - New feature to reproduce incident conditions in a controlled environment
  - Replay incident requests with original payloads
  - Verify root cause hypotheses through simulation
  - Detailed replay results with confidence scoring
  - Expandable sections for request details, behavior analysis, and error logs
  - API endpoint: `POST /api/incidents/:id/replay`

- **Resolution Runbook** - New feature to generate automated remediation procedures
  - Step-by-step resolution procedures with time estimates
  - Code and configuration change suggestions
  - Verification criteria for each step
  - Comprehensive rollback plans with trigger conditions
  - Risk assessment and mitigation strategies
  - Export runbooks as Markdown for documentation
  - API endpoint: `POST /api/incidents/:id/runbook`

- **New TypeScript Types**
  - `IncidentReplayResult` - Replay execution results and findings
  - `ResolutionRunbook` - Complete runbook structure
  - `ResolutionStep` - Individual resolution procedure steps
  - `VerificationCriteria` - Success verification metrics
  - `RollbackPlan` - Rollback procedures and conditions
  - `RiskAssessment` - Risk evaluation and mitigation

- **New UI Components**
  - `IncidentReplayView` - Interface for triggering and viewing incident replays
  - `ResolutionRunbookView` - Interface for displaying and exporting resolution runbooks

- **Sidebar Navigation Updates**
  - Added "Incident Replay" tab with Play icon
  - Added "Resolution Runbook" tab with BookOpen icon
  - Both tabs marked as "NEW" features

### Changed
- Updated `apiClient` with new methods: `replayIncident()` and `generateRunbook()`
- Enhanced `App.tsx` with runbook state management and navigation
- Updated sidebar navigation to include new feature tabs

### Technical Details
- Backend endpoints added to `server.ts` for replay and runbook generation
- Mock data added to `mockData.ts` for realistic replay and runbook examples
- Type definitions added to `types.ts` for new data structures
- API client methods added with fallback to mock data for offline testing

## [1.0.0] - 2026-08-30

### Added
- Initial release of TraceMind AI
- Real-time incident detection
- AI-powered root cause analysis using Gemini AI
- Parallel evidence investigation (logs, metrics, deployments)
- Interactive dashboard with dark-themed UI
- Log explorer with advanced filtering
- Service health monitoring
- Deployment tracking
- Code fix recommendations
- Demo mode with simulated incidents

### Features
- **Dashboard Overview** - System health, active incidents, key metrics
- **Services View** - Microservice health status monitoring
- **Incidents View** - Incident tracking and management
- **AI Investigations** - Autonomous root cause analysis
- **Log Explorer** - Advanced log filtering and search
- **Metrics View** - Performance metrics visualization
- **Deployments View** - Deployment history and correlation
- **Incident Report** - AI-generated incident documentation
- **Architecture View** - System architecture visualization

### Tech Stack
- Frontend: React 19, TypeScript, Tailwind CSS 4
- Backend: Express.js, Node.js
- Build Tool: Vite 6
- AI Integration: Google Gemini AI (@google/genai)
- Charts: Recharts
- Icons: Lucide React
- Animations: Motion
