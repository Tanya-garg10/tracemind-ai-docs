Get started with TraceMind AI in minutes using this quick start guide.

## Prerequisites

- Node.js 18+ 
- npm or bun package manager
- (Optional) Google Gemini API Key for AI-powered features

## Installation

1. **Clone the repository**
```bash
git clone https://github.com/Tanya-garg10/TraceMind-AI-Autonomous-API-Failure-Detection-Root-Cause-Analysis.git
cd TraceMind-AI-Autonomous-API-Failure-Detection-Root-Cause-Analysis
```

2. **Install dependencies**
```bash
npm install
```

3. **Set up environment variables**
```bash
cp .env.example .env
```

Edit `.env` and add your Gemini API Key (optional - falls back to mock data):
```
GEMINI_API_KEY=your_gemini_api_key_here
APP_URL=http://localhost:3000
```

## Running the Application

### Development Mode
```bash
npm run dev
```

The application will be available at http://localhost:3000

### Production Build
```bash
npm run build
npm start
```

## First Steps

1. **Launch the application** - Navigate to http://localhost:3000
2. **View the dashboard** - See system health, active incidents, and key metrics
3. **Trigger a demo incident** - Use the "Simulate Incident" button to see the system in action
4. **Run AI investigation** - Click "Investigate" to trigger autonomous root cause analysis
5. **Explore incident replay** - Navigate to "Incident Replay" to reproduce incident conditions
6. **Generate resolution runbook** - Create detailed remediation procedures

## Demo Mode

TraceMind AI includes a demo mode with simulated incidents. Use the demo controls to:
- **Trigger simulated API failures** - See how the system detects and analyzes incidents
- **Reset system state** - Return to healthy baseline for testing
- **Test AI features** - Explore investigation, replay, and runbook generation
